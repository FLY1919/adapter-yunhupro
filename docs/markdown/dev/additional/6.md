# 内置访问链接（App 深链）

> 本页内容整理自云湖社区文章：[https://www.yhchat.com/c/p/46876](https://www.yhchat.com/c/p/46876)，原作者：inltree。

云湖客户端支持使用**内置访问链接**（App 深链），以及与之对应的网页地址。借助这些链接，可以在消息、文档或网页中直接引导用户打开某个用户、群组、机器人、社区板块或帖子页面。

:::tip 温馨提示
带有**颜色渲染或下划线**的文本通常都可以点击跳转；如果点击后无法跳转，请尝试更换浏览器，或在云湖客户端内打开。
:::

## 链接总览

下表中 `<id>` 为占位符，请替换为实际的用户 ID、群组 ID、机器人 ID、板块 ID 或帖子 ID。

| 目标       | 网页地址                                                 | 内置访问链接                          |
| ---------- | -------------------------------------------------------- | ------------------------------------- |
| 用户主页   | `https://www.yhchat.com/user/homepage/<id>`              | `yunhu://chat-add?id=<id>&type=user`  |
| 用户分享页 | `https://www.yhchat.com/user/homepage/<id>?userId=<id>`  | —                                     |
| 群组分享页 | `https://www.yhchat.com/group/homepage/<id>?userId=<id>` | `yunhu://chat-add?id=<id>&type=group` |
| 机器人主页 | `https://www.yhchat.com/bot/homepage/<id>?userId=<id>`   | `yunhu://chat-add?id=<id>&type=bot`   |
| 社区板块   | `https://www.yhchat.com/c/<id>`                          | `yunhu://alley-detail?id=<id>`        |
| 社区帖子   | `https://www.yhchat.com/c/p/<id>`                        | `yunhu://post-detail?id=<id>`         |

:::warning 注意
`yunhu://chat-add` 的 `type` 参数必须与目标类型一致：用户使用 `user`，群组使用 `group`，机器人使用 `bot`。用户 ID、群组 ID 与机器人 ID 分别独立，请勿混用。
:::

## 使用示例

以用户 `5377447` 为例：

- 网页端：[@Lin(5377447)](https://www.yhchat.com/user/homepage/5377447)
- 客户端内置访问：[打开该用户](yunhu://chat-add?id=5377447&type=user)

在 Markdown 中也可以直接写成超链接：

```md
[@Lin(5377447)](https://www.yhchat.com/user/homepage/5377447)[[内置访问]](yunhu://chat-add?id=5377447&type=user)
```

## 在适配器中的应用

发送合并转发消息时，适配器会通过用户 ID 查询对应身份，并把发送者名称渲染成 `yunhu://chat-add` 内置访问链接：当目标为用户时使用 `type=user`，为机器人时使用 `type=bot`。这样在客户端点击转发消息中的名称，即可直接打开该用户的个人卡片。
