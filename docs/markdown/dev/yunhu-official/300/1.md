# 事件订阅详述

> 官方文档：<https://www.yhchat.com/document/300-310>

事件订阅会将消息、群成员变化、机器人关注状态和按钮交互等事件，通过 `HTTP POST` 以 JSON 格式推送到服务端。

## 事件列表

| 事件名称 | 取值 | 文档 |
| --- | --- | --- |
| 普通消息事件 | `message.receive.normal` | [消息事件](./1/message) |
| 指令消息事件 | `message.receive.instruction` | [消息事件](./1/message) |
| 关注机器人事件 | `bot.followed` | [关注事件](./1/follow) |
| 取消关注机器人事件 | `bot.unfollowed` | [关注事件](./1/follow) |
| 加入群事件 | `group.join` | [群成员事件](./1/group) |
| 退出群事件 | `group.leave` | [群成员事件](./1/group) |
| 按钮事件 | `button.report.inline` | [交互事件](./1/interaction) |
| 快捷菜单事件 | `bot.shortcut.menu` | [交互事件](./1/interaction) |

## 通用结构

所有事件使用相同的外层结构：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `version` | `string` | 事件内容版本号 |
| `header` | `Header` | 事件基础信息 |
| `event` | `Event` | 事件内容，结构会随 `eventType` 变化 |

### Header

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `eventId` | `string` | 全局唯一的事件 ID |
| `eventTime` | `number` | 事件产生时间，13 位毫秒时间戳 |
| `eventType` | `string` | 事件类型 |

```json
{
  "version": "1.0",
  "header": {
    "eventId": "f10b35f5ea3b46968eeb44a858c1e0e9",
    "eventType": "message.receive.normal",
    "eventTime": 1761936492340
  },
  "event": {}
}
```
