# 机器人发送消息

> 官方文档：<https://www.yhchat.com/document/400-410>

机器人通过消息发送接口向用户或群组发送消息。不同消息类型只在 `contentType` 和 `content` 结构上有所区别。

## 请求地址

`POST https://chat-go.jwzhd.com/open-apis/v1/bot/send?token=YOUR_TOKEN`

```bash
Content-Type: application/json
```

## 公共参数

| 字段 | 类型 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| `recvId` | `string` | 是 | 接收对象 ID。用户为 `userId`，群为 `groupId` |
| `recvType` | `string` | 是 | 接收对象类型：`user` 或 `group` |
| `contentType` | `string` | 是 | 消息类型 |
| `content` | `object` | 是 | 消息内容 |
| `parentId` | `string` | 否 | 引用消息 ID |

## 消息类型

| 类型 | 说明 |
| --- | --- |
| [文本](./1/text) | 发送纯文本，可附带 `@` 用户和按钮 |
| [图片](./1/image) | 发送已经上传的图片 |
| [Markdown](./1/markdown) | 发送 Markdown 文本 |
| [HTML](./1/html) | 发送 HTML 文本 |
| [文件](./1/file) | 发送已经上传的文件 |
| [视频](./1/video) | 发送已经上传的视频 |
| [语音](./1/audio) | 机器人接口不支持直接发送语音，适配器使用 A2UI 播放器 |
| [A2UI](./1/a2ui) | 发送 A2UI JSONL，由云湖客户端渲染交互组件 |
| [按钮](./1/buttons) | `Button` 对象结构及完整示例 |

## 响应

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `code` | `number` | 响应代码，成功时为 `1` |
| `msg` | `string` | 响应信息 |
| `data` | `object` | 返回数据 |

```json
{
  "code": 1,
  "data": {
    "messageInfo": {
      "msgId": "a54ec67c089044dfa4241b9dd0a57f8d",
      "recvId": "307149245",
      "recvType": "group"
    }
  },
  "msg": "success"
}
```
